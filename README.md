# 紙芸書籍の「折り・展開」と絵柄の連動 — p5.js デモ

しかけ絵本・立体カードの魅力は、紙が折れて立ち上がる「構造」と、その紙に
印刷された「絵柄」が折り目に沿って組み合わさる、両者の連動にあります。

このデモは、その連動を p5.js（WEBGL）で再現した最小プロトタイプです。

## 何をしているか

- **V 折り（テント折り）構造**を、開き具合（0〜1）に応じて立ち上げます。
- その折り面に、`createGraphics()` で生成した**絵柄（顔）をテクスチャとして
  貼り付け**ます。
- 折り目を中央のガイド線として、**左の折り面＝絵柄の左半分（u 0〜0.5）、
  右の折り面＝右半分（u 0.5〜1）** を対応させています。
  → 閉じた状態では一枚の平面の絵、開くにつれて絵が左右に分かれて立ち上がる、
  という「構造と絵柄の連動」を、1 枚のテクスチャで再現しています。

## 操作方法

- **スライダー**：紙を閉じる／開く（折りの高さを変える）
- **マウスドラッグ**：視点を回転（orbitControl）
- **マウスホイール**：ズーム

## 技術メモ

- p5.js 1.9.4（WEBGL モード）
- `texture()` + `vertex(x, y, z, u, v)` による手動 UV マッピング
- 開き具合 → 頂点高さのイージング（easeInOutCubic）
- 絵柄は実行時に `createGraphics()` で生成（外部画像不要）

## 実行方法

```
cd paper-popup-demo
python -m http.server 8765
# ブラウザで http://127.0.0.1:8765/index.html を開く
```

> `index.html` と同じディレクトリに `p5.min.js`（ローカル同梱）が必要です。
